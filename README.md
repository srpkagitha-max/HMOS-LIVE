# HMOS Production Clean Build

Clean GitHub Pages build of **Hostel Management Operating System (HMOS)**.

## Upload these files to the repository root

- `index.html`
- `app.js`
- `firebase-service.js`
- `firebase-config.js`
- `styles.css`
- `service-worker.js`
- `manifest.json`
- `404.html`
- `icon-192.png`
- `icon-512.png`
- `firestore.rules`
- `firestore.indexes.json`

## GitHub Pages

In **Settings → Pages** choose:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

The existing Firebase project and Firestore data are unchanged.
Deployment refresh
